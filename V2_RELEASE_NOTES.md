# ISERS v2.0 Release Notes

This release upgrades the finalized v1.2 rostering application into the competition/startup build discussed with the project team.

Major additions: advanced employee portal, shift acceptance/decline, two-strike suspension/reactivation, automated replacement, richer preferences, map/nearest matching, travel-aware constraints, cross-manager reservation protection, candidate blocker explanations, shift marketplace, compliance configuration, workforce intelligence, notifications and expanded testing.

Python 3.10+ compatibility from v1.2 is retained.
