# ISERS v2.0 Final Handoff

## Fastest Windows demo
1. Extract the ZIP.
2. Close older ISERS server windows using port 8000.
3. Double-click `start_windows.bat`.
4. Open `http://127.0.0.1:8000`.

## Recommended competition demo flow
1. Manager Command Centre.
2. Employee profiles, skills and preferences.
3. Shift requirements and venue coordinates.
4. Generate roster and explain hard/soft layers.
5. Candidate Explorer: show skillset, position, exact blockers, distance and workload.
6. Publish roster and switch to employee account.
7. Employee accepts/declines an offer; demonstrate automatic replacement.
8. Demonstrate second non-acceptance suspension and reactivation workflow if desired.
9. Show map/nearest eligible worker.
10. Show shift marketplace/swaps.
11. Show Workforce Intelligence and What-if simulation.
12. Show compliance rules, audit and reports.
